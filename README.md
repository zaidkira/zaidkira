## 🚀 Featured Projects

### ❤️ My Health First / PharmaSmart *(final-year project)*
Wearable health bracelet (ESP32-C3 SuperMini + MAX30102 for heart rate/SpO₂ + MPU6050 for steps) with a multi-role web platform for patients, doctors and pharmacies.
`ESP32-C3` `React` `Node.js` `Supabase` `KiCad`

### 🌋 Seismic Risk Analysis for CATNAT Insurance
Risk analysis of 37,000+ insurance contracts using Python pipelines, QGIS mapping with RPA 99 seismic zoning, CatBoost ML models and PyQt5 dashboards.
`Python` `QGIS` `CatBoost` `PyQt5`

### 🌡️ Industrial PID Temperature Controller
ESP32-based controller for AC 220V loads with SSR switching and thermocouple sensing, including full KiCad schematic and PCB.
`ESP32` `KiCad` `Power electronics`

`Arduino` `ESP32-S3` `INA219` `I2C`

`Electron` `React` `Vite` `Node.js` `MongoDB`
